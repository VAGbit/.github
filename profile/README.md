## About Us

**VAGbit** develops innovative hardware and software solutions for Volkswagen Group vehicles.

Our mission is to bridge the gap between factory automotive electronics and modern technology through intelligent CAN bus communication, embedded systems and advanced diagnostic tools.

From vehicle network analysis to custom infotainment integration, we build practical solutions for automotive enthusiasts, developers and engineers.

**Built for enthusiasts. Engineered for innovation.**

---

## Our Projects

### [MIBridge](https://github.com/VAGbit/VAGbit-MIBridge)
**Automotive Infotainment Integration**

A CAN bus communication platform designed to connect different generations of Volkswagen Group vehicle electronics.

- PQ and MQB platform integration
- Infotainment communication
- CAN bus message translation
- Vehicle data emulation
- Embedded gateway development

[View Repository](https://github.com/VAGbit/VAGbit-MIBridge)

### [VAGbit Visual](https://github.com/VAGbit/VAGbit-Visual)
**CAN Bus Analysis & Visualization**

A modern application for monitoring, analyzing and visualizing automotive communication.

- Live CAN bus monitoring
- Vehicle signal visualization
- CAN message filtering and analysis
- Data logging and export
- Embedded device connectivity

[View Repository](https://github.com/VAGbit/VAGbit-Visual)

### [CANDash](https://github.com/VAGbit/VAGbit-CanDash)
**Real-Time Vehicle Telemetry**

A customizable dashboard platform for displaying real-time vehicle information.

- Live engine and vehicle data
- Customizable gauges and dashboards
- CAN bus signal decoding
- Performance monitoring
- Embedded display integration

[View Repository](https://github.com/VAGbit/VAGbit-CanDash)

## Development Philosophy

We believe automotive electronics should be accessible, adaptable and continuously evolving.

Our work is driven by three core principles:

**Innovation**  
Exploring new possibilities in automotive electronics and vehicle communication.

**Engineering**  
Creating reliable, efficient and practical hardware and software solutions.

**Accessibility**  
Making complex automotive technologies easier to understand, analyze and integrate.
